# Brand

How mori looks and sounds. Use this for the website, the README, the CLI's messages and anything
else that speaks for the project.

## Name

- **mori**, always lowercase, including at the start of a sentence.
- It comes from **森 (mori)**, Japanese for forest. The character is three 木 (tree): one above,
  two below. mori tends a forest of worktrees.
- Show 森 in a proper font. Don't hand-draw it or imitate brush lettering.

## Tagline

*memento mori: every tree dies; your work doesn't.*

Trees come and go; mori makes sure the work in them is never lost.

## Voice

- **Plain.** Short sentences, everyday words. Say what happens, not how impressive it is.
- **Calm.** mori deals with people's work; it never sounds alarmed or flippant about it.
- **A little wry**, where it helps. Never at the reader's expense.
- **Honest.** mori is a hobby project and pre-alpha, and says so.

## Values

- Never lose work.
- A high bar: great engineering, product and UX.
- No slop.

- **Lockup:** the logo followed by the name **mori** in the body font.

## Type

The site's default sans-serif for text, and its monospace for code and commands. No display or
novelty fonts.

## Using Japanese respectfully

- Use 森 for what it means, forest, and say so plainly.
- No stereotyped "Japanese" styling: no imitation-Asian fonts, torii gates, cherry blossoms,
  samurai or zen clichés. The forest carries the identity.
- 森 is also a common Japanese family name. Don't write copy that treats mori as a person.
- Have a native speaker review any new Japanese text before it ships.
