# Code of conduct

mori follows the
[Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).
It applies everywhere the project happens: issues, pull requests, reviews, and any other mori space.

In short: be kind, assume good faith, and keep criticism about the work, not the person. Harassment,
personal attacks and discrimination aren't tolerated.

## Reporting

mori is small, and a private channel for conduct reports hasn't been set up yet. It will be as the
project grows. Until then, contact the maintainer through GitHub.
